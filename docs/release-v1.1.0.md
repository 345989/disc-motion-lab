## 三维出盘实验台 · 离线版 1.1

在浏览器里拆解 175 g 极限飞盘的正手和反手出盘。逐帧观察肩、肘、腕如何带动飞盘，跳到离手瞬间查看盘面姿态，再沿完整轨迹观察飞行。

- **动作对照**　支持左右手、正反手，以及基础参考、身前推盘、躯干主导、翻掌、抬鼻和早晚释放等教学预设。可手动打开「叠加参考动作」，从俯视、侧视和握盘特写等角度对照。
- **动作和飞行参数**　可调整关节角度、连杆尺寸、握点、盘面俯仰／滚转／偏航、释放相位、风和气动系数。关掉空气后，可对照真空中的抛物线。
- **保存和复现**　支持导入、导出配置 JSON，导出轨迹 CSV 和完整模拟 JSON。可在「运动指令」编辑关节关键帧，也可从浏览器控制台调用 `window.DiscLab`。
- **离线使用**　渲染和物理计算在浏览器中运行。支持 WebGL，缺少 WebGL 时自动切换至 Canvas 兼容视图。
