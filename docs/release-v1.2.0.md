## 拖动动作轨道，调整出盘时序 · 离线版 1.2

把大臂挥动、小臂展开、手腕出盘放到同一条时间轴上对照。试着将手腕出盘向后拖一点，再跳到释放瞬间，观察盘速、自旋、方向和落点怎样变化。

- **多轨拖动**　默认显示大臂挥动、小臂展开和手腕出盘三轨，可展开大臂抬升、小臂轴向旋转、手腕屈伸、骨盆转动和胸廓转动，共八轨。拖动色块平移整条关节曲线，拖动两端改变持续时间，松手后更新模拟。
- **精确调整与复位**　可输入起止时间，也可用方向键以 1 ms 微调，按住 Shift 时步进 10 ms。支持单轨或全部时序复位。释放线可定位离手瞬间，释放相位在参数面板独立设置。
- **默认叠加参考动作**　打开即显示基础参考动作，方便从同一视角比较关节路径、握点和释放姿态。
- **时序随配置保存**　各轨的平移和伸缩保存在配置 JSON 的可选 `timing` 字段中，基础关键帧角度仍可独立编辑。v1.1 配置可以直接导入。
