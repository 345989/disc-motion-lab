离线版 1.1 验证记录
日期：2026-11-11

已完成
- HTML 采用内嵌普通脚本（IIFE）与内嵌 CSS；不依赖 module 文件加载或本地服务器。
- 构建确认外部模块依赖数量为 0；无外链脚本、样式或字体。
- HTML 中的内容安全策略禁用程序发起外部连接；论文链接由使用者主动打开。
- TypeScript 类型检查通过。
- 11 项物理测试通过：
  1. 28 组动作/持盘手组合均产生有限数值及单位四元数。
  2. 三维姿态变化中，握点保持在盘缘，连杆长度恒定。
  3. 真空质心抛物线与世界角动量守恒。
  4. 释放速度满足刚体握点速度关系。
  5. 左手镜像按轴矢量规则转换角速度。
  6. 升力不沿相对气流做功，阻力耗散。
  7. 各关节的速度投影贡献之和与释放速度一致。
  8. 位置驱动运动与质量无关，速度随时间尺度成反比。
  9. 释放时的位置、姿态、速度连续，正反手自旋符号相反。
  10. 以一半步长运行时飞行结果收敛。
  11. 配置可以往返序列化，并拒绝无效参数和过激关键帧。
- 在独立 Canvas 绘制环境中检查反手、正手握盘特写、翻掌和完整轨迹。
