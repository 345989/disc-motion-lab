# v1.4.0 验证记录

验证环境：Windows、Node.js 24.22.1、pnpm 11.25.0、本机 Chrome（Playwright 自动操作）。网页通过本地 `file://` 打开，浏览器上下文设置为离线。

## 数值与接口

`pnpm run typecheck` 通过；`pnpm test` 共 **21 项通过**。

- 保留原有 11 项运动学与飞行测试，涵盖正反手、左右手和全部动作预设、刚体握点关系、动量与重力轨迹、气动耗散、关节贡献、释放连续性、步长收敛及配置校验。
- 新增 10 项握持测试，涵盖反算的平动力与转矩平衡、解析平动载荷、逐点摩擦上限、相对动能耗散、充分／弱／零握力、镜像、提前释放连续性及握持步长减半。
- 28 组真实握盘预设／手别组合均产生有限状态和单位四元数，各点施力满足对应静／动摩擦预算。
- 零摩擦与接触点重合时能返回明确的不可满足需求，不把无穷大混入 JSON。
- 缺少 `grip` 字段的旧配置使用理想握持默认值；不合法摩擦系数或接触参数会被拒绝。

## 与 v1.3.1 对照

直接在旧版和新版 HTML 中运行相同的 **56 组配置**，组合正反手、左右手、七种预设以及原始／修改后的轨道时序。去除新版新增的接触数据与字段说明后，释放结果、指标和完整飞行帧 **逐项一致**。

## 浏览器交互

- 「真实握盘」默认关闭，「叠加参考动作」默认开启。
- 开启默认真实握盘后出现滑移、接触丢失和提前释放，`sampleState()` 的实际盘心与 `samplePose()` 的预定盘心分离。
- 接触编辑器的鼠标与触控拖动、方向键微调、应用、取消与 Escape 关闭通过。
- 配置导出／重新导入保留接触点、权重及开关；旧版示例配置可导入。
- 八条关节轨道可展开，时序编辑继续生效。
- 握盘 CSV 包含滑动与释放状态，各行列数一致；充分握力与零握力接口检查通过，零握力立即释放的界面显示通过。
- WebGL 和 Canvas 两种渲染模式均运行；桌面 1440 px、手机 390 px 宽度没有页面横向溢出，接触编辑器和结果面板完成截图检查。
- 页面没有未捕获错误，也没有发出 HTTP 请求。

## 发布包

开发者 ZIP 包含源码、锁文件、文档、测试、示例、许可证和对应离线 HTML，排除 `node_modules`、Git 元数据及工作文件。解压后使用锁定依赖执行类型检查、测试与构建，并核对生成 HTML 的 SHA-256 与发布 HTML 一致。Release 的 `SHA256SUMS.txt` 同时列出 HTML 和开发者 ZIP 的校验值。

这些检查验证本版数值实现、旧功能兼容性和打包结果。模型采用的平面接触自由度、力分配与参数来源详见 [握持模型](../source/GRIP_MODEL.md)。
