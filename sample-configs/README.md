# 示例配置

在 HTML 的「导入」按钮中选择 JSON 文件即可加载。每份配置都可继续调整，再导出保存。

| 文件 | 实验 |
| --- | --- |
| `backhand-reference.json` | 反手基础参考，理想握持 |
| `forehand-reference.json` | 正手基础参考，理想握持 |
| `backhand-push.json` | 反手身前推盘 |
| `forehand-roll.json` | 正手翻掌 |
| `backhand-grip-slip.json` | 反手真实握盘，20 N、静／动摩擦系数 0.6／0.5 |
| `forehand-grip-slip.json` | 正手真实握盘，20 N、静／动摩擦系数 0.6／0.5 |

后两份用于观察滑移与提前脱手。导入后可关闭「真实握盘」比较预定动作，或调整握力、时序与接触点，观察受力需求和释放结果。选择新的动作预设会恢复默认参数。
