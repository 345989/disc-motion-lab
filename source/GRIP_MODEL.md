# 握持、摩擦与滑移模型

v1.4.0 在原有三维关节链与六自由度飞行之间加入可选的握持接触层。入口为 `lib/disc/grip.ts`，与关节关键帧、多轨时序、飞行动力学共用同一份配置。

## 两种实验模式

- **理想握持**（默认）：飞盘沿原有约束运动，在计划时刻释放。逐时刻反算各接触点的切向力，以及满足当前力分配所需的总法向力。预设握力不会改变动画与飞行结果。
- **真实握盘**：各接触点拥有有限摩擦能力。静摩擦可维持约束时随手运动；超限后计算相对滑移及相对转动。接触点滑出盘缘后失效，全部失效时提前脱手。若始终存在接触，则在计划释放时刻结束握持。

释放状态的位置、姿态、线速度和角速度直接交给原有自由飞行积分器。身体关节始终按用户安排的曲线运行，灰色参考动作使用理想握持。

## 本版计算范围

接触模型在随手运动的盘面中计算两个平移自由度和一个绕盘面法线的转动自由度。盘面法向的位置、俯仰及滚转由手部提供理想引导。有限法向载荷用于计算切向摩擦上限，**不用于求解法向分离或俯仰、滚转方向的握持能力**。

三个点表示拇指、食指和中指的有效接触区域。盘面上的接触位置参与摩擦力与力矩计算；图中的上下高度仅用于辨认手指。盘缘勾持、手指形变、柔性接触面积、皮肤湿度随时间变化和法向载荷主动控制可作为后续扩展。

## 默认参数与资料

| 参数 | 初值 | 含义与依据 |
| --- | --- | --- |
| `enabled` | `false` | 默认保留理想握持，便于和旧版直接对照 |
| `normalForce` | 20 N | 三个接触点的正法向载荷之和，默认分配为 10 / 5 / 5 N |
| `staticFriction` | 0.6 | 静摩擦系数，可调整 |
| `kineticFriction` | 0.5 | 动摩擦系数，可调整，要求不大于静摩擦系数 |
| `contacts[].weight` | 0.5 / 0.25 / 0.25 | 正权重自动归一化，决定每点法向载荷 |
| `contacts[].u, v` | 见下表 | 接触点在盘面内的位置，以半径为单位 |

[Seo 与 Armstrong（2009）](https://pmc.ncbi.nlm.nih.gov/articles/PMC6756432/)在铝和橡胶表面进行了单指腹 1、10、20 N 载荷实验。本项目据此选择单点数牛顿至十牛顿的初始量级，再将三点载荷合计为 20 N。

[Derler 与 Rotaru（2013）](https://doi.org/10.1016/j.wear.2012.11.030)讨论皮肤摩擦及黏滑，文中概述干燥皮肤摩擦系数约 0.5 的量级。[Adams 等（2013）](https://pmc.ncbi.nlm.nih.gov/articles/PMC3565724/)综述了指腹摩擦受材质、载荷与皮肤状态影响的机制。

**20 N、0.6 / 0.5 的组合是参考这些量级选择的可调初值，静动差与接触布局属于本项目的建模设定；这些论文没有测量本项目使用的 175 g 飞盘握法。** 获得自己的握力或摩擦实验数据后，可以直接替换这些参数。

| 接触点 | 反手 `(u, v)` | 正手 `(u, v)` |
| --- | --- | --- |
| 拇指 | `(0.72, 0)` | `(0.72, 0)` |
| 食指 | `(0.90, 0.13)` | `(0.82, 0.13)` |
| 中指 | `(0.90, -0.13)` | `(0.94, -0.13)` |

`u` 从理想盘心指向握点 G，`v` 为盘面切向；左手布局随模型镜像。编辑器限制 `sqrt(u² + v²) ≤ 0.98`，让初始点位于盘内。允许的总法向力范围为 0～2000 N，用于探索约束是否能成立；这一上限是计算范围。较快的预定加速度、较小的手指间距，以及本版仅靠盘面摩擦传矩的设定，都可能使反算握力很大。

## 反算接触力

设理想盘心加速度为 `a₀`，世界重力为 `g`，理想盘面姿态为 `R₀`，局部角加速度为 `α`。`P` 取盘面内的 x、z 分量：

```text
F = m P[R₀⁻¹(a₀ − g)]
τ = I_axial α_y
Σ fᵢ = F
Σ (rᵢ × fᵢ)_y = τ
```

这里 `rᵢ` 为接触点相对盘心的位置，`fᵢ` 是盘面内切向力。以归一化法向载荷份额 `wᵢ` 分配受力，最小化 `Σ |fᵢ|² / wᵢ`，在满足力与转矩的条件下求得一组确定解：

```text
r̄ = Σ wᵢ rᵢ
D = Σ wᵢ |rᵢ − r̄|²
J(x, z) = (z, −x)
fᵢ = wᵢ [F + (τ − (r̄ × F)_y) / D · J(rᵢ − r̄)]
N_required = maxᵢ |fᵢ| / (μ_s wᵢ)
```

`N_required` 是**满足这一加权受力分配**所需的总法向力，不是遍历所有可能力分配后的全局最小握力。所有点重合时，若剩余转矩无法满足，或零静摩擦系数下仍需要切向力，返回 `null`，界面显示「无有限解」。

界面的「摩擦需求」是 `Σ |fᵢ|`，包括相互抵消但传递转矩的力，不等于合力的模长。静摩擦判断逐点进行，不能只比较总需求和 `μ_s N`。`normalReaction` 另行报告理想运动所需的法向引导合力，与上表的三个正法向载荷之和不同。

## 有限摩擦与滑动

设相对理想盘心的平面位移为 `d`，相对转角为 `θ`。世界状态为：

```text
C = C₀ + R₀ d
Q = Q₀ · Q_y(θ)
v = v₀ + Ω × (R₀ d) + R₀ ḋ
ω = Ω + n θ̇
```

接触点随手移动。实际盘心改变后，接触点相对盘心的位置为 `rᵢ = anchorᵢ − d`，其相对滑动速度为 `uᵢ = ḋ + θ̇ J(rᵢ)`。

积分在随手运动的坐标系中进行，包括科里奥利项、欧拉项和离心项：

```text
d̈ = P[R₀⁻¹(g − a₀) − 2Ω_local × ḋ − α_local × d
       − Ω_local × (Ω_local × d)] + Σ fᵢ / m
θ̈ = Σ (rᵢ × fᵢ)_y / I_axial − α_local,y
```

相对速度接近零且上述加权静摩擦分配在每点上满足 `|fᵢ| ≤ μ_s Nᵢ` 时保持静止约束。否则用动摩擦冲量求解，逐点满足 `|pᵢ| ≤ μ_k Nᵢ Δt`。求解器采用块投影 Gauss–Seidel，每个二维冲量在其圆形库仑上限内求解，使相对动能降低，最多 60 次迭代。速度收敛至零且静摩擦条件重新成立时，可在已有位移处重新保持，不会强制把飞盘拉回原位。

默认握持步长不大于 1/960 s，均分到计划释放时刻；飞行保持原来的 1/480 s 二阶积分。某点距实际盘心超过半径时失效，其法向份额不转移给其他点。本次出手中不重新激活已失效的接触点。零法向力直接在 t = 0 释放。

## 接口、时间与数据

- `DiscLab.getConfig().grip`：读取开关、握力、摩擦系数与接触点；修改后通过 `setConfig()` 应用。
- `DiscLab.getSchema().grip`：参数范围、单位、坐标约定和对应正反手默认值。
- `DiscLab.analyzeGrip(config?)`：握持过程、峰值、首次滑动、释放时间和释放原因。
- `DiscLab.samplePose(phase)`：继续返回**预定动作**的关节、握点和理想盘心。
- `DiscLab.sampleState(seconds)`：返回**实际飞盘**的位置、姿态、速度和角速度，包含滑移与自由飞行；落地或达到飞行时限后返回末帧。
- `DiscLab.simulate(config?)`：保留原有释放、轨迹和指标字段，新增 `grip` 与动作起点计时的 `releaseTime`。

握持 `samples[].t`、`states[].t` 从动作起点计时；自由飞行 `frames[].t` 沿用旧版，从实际释放计时。`grip.states` 到实际释放为止；`grip.samples` 的反算需求继续到计划释放，方便比较原定动作需要多少握力。提前释放后的相对位移和转角保留脱手时数值，实际后续飞盘状态使用 `sampleState()` 或飞行帧读取。

`samples` 中运动状态对应时刻 t，接触力对应从 t 开始的积分区间。`contactForces` 是实际施加的各点力的模长，`demandForces` 是预定运动反算的各点需求。释放后实际力、接触能力和接触标记清零；反算需求仍可读取。`frictionPower` 是摩擦冲量引起的相对动能变化除以步长，用于检查摩擦耗散，不是世界坐标下飞盘获得的功率。

「握盘数据 CSV」导出上述时序数据，无法满足的法向力需求留空；完整模拟 JSON 用 `null` 表示。`release.contributions` 仍表示关节运动学速度贡献，在真实握盘模式下按实际释放时刻的预定动作计算，不能用其和解释滑动后的实际盘速。界面中的贡献条及速度／自旋小图明确展示预定动作；「释放与结果」展示实际释放结果。

旧配置不含 `grip` 时自动补充理想握持默认值。配置版本仍为 `version: 1`，已有多轨时序与关键帧数据保留。

## 验证

`tests/grip.test.ts` 覆盖反算的力与转矩平衡、解析平动案例、逐点摩擦上限、相对能量耗散、理想／充分握力／弱握力／零握力、左右手镜像、提前释放连续性与步长减半收敛。既有 `physics.test.ts` 继续检查运动学和飞行不变量。
